# Projeto Acad

Projeto acadêmico criado com React + Vite.

## Como rodar

```bash
npm install
npm run dev
```

## Estrutura principal

```txt
src/
├── assets/       # imagens e arquivos estáticos usados no React
├── components/   # componentes reutilizáveis da interface
├── data/         # dados mockados/listas usadas pelas páginas
├── pages/        # páginas/telas principais do projeto
├── styles/       # estilos globais e variáveis CSS
├── templates/    # layouts/base visual das páginas
├── App.jsx       # composição principal da aplicação
└── main.jsx      # ponto de entrada do React
```

## Observação

O projeto ainda não usa React Router porque só existe uma página. Quando tiver mais telas reais, o próximo passo é adicionar rotas.
